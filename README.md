# Heart Disease Prediction using Machine Learning

**Author:** Vedha.S 
**Branch:** B.Sc Computer Science  

## About
This project predicts whether a patient has heart disease using machine learning models:
- Logistic Regression  
- Decision Tree  
- Random Forest  

The UCI Heart Disease dataset is used for training and evaluation.

## Tech Stack
- Python  
- NumPy  
- Pandas  
- Matplotlib  
- Seaborn  
- Scikit-learn  

## Features
- Data analysis and preprocessing  
- Data visualization  
- Model training and testing  
- Model comparison  
- Best model selection
